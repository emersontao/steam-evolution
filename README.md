# steam-evolution

The steam world evolution model & steam atmospheric escape grids from Tao et al. 2026 (in prep).

* `evolution_guide.ipynb` walks you through how to use the evolution code and simulate the evolution of your own steam worlds
* `Demo_grid-H2O-escape-rates.ipynb` dives deeper into analysis of H2O escape rates from [`Wind-AE`](https://github.com/mibroome/wind-ae)
* `paper_plots.ipynb` and `Models/plot_module.py` are outdated (will be fixed soon! -July 27 2026)
